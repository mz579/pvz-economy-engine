# Dashboard 截图说明

启动页面：

```bash
streamlit run app.py
```

仓库包含“均衡巡逻、150 阳光、20 格”下生成的两张实际页面截图：

- `dashboard.png`：1280×720 桌面端首屏；
- `dashboard-mobile.png`：390×844 移动端首屏。

当前截图对应 `土豆雷 ×5 + 小喷菇 ×6 + 灯笼草 ×1`：使用 150 阳光、占用 12/20 格，其余 8 格按 30% 单植物集中度规则真实保留为空位。

更新截图时应覆盖：

1. 侧栏僵尸模式、阳光和格子参数；
2. 作战终端、分析状态和资源计数器；
3. 推荐植物卡、真实数量草坪网格、未使用空格和 30% 集中度说明；
4. 至少一张图能继续向下查看市场证据和候选对比；
5. 页面级无横向滚动、文字重叠或内容裁切。

截图前必须点击“🚀 开始分析”，并确认草坪格子数、推荐数量和资源统计一致。移动端允许页面纵向滚动，表格允许组件内部横向滚动。

仓库不提供或要求任何官方 PvZ 素材；截图中的视觉元素应全部来自页面的 emoji 和原创 CSS。
