末日菜园作战室 — 下载后先看这里
================================

运行条件：Python 3.10 或更高版本，第一次安装依赖时需要网络；慢速网络可能需要 5–15 分钟。

Windows：
1. 解压整个压缩包，不要直接在压缩包里双击。
2. 双击 start_windows.bat。
3. 等待浏览器打开 http://localhost:8501。
4. 使用期间不要关闭启动窗口，关闭窗口会同时停止网站。

macOS / Linux：
1. 解压后进入项目目录。
2. 执行：bash start_unix.sh
3. 浏览器访问 http://localhost:8501。

使用自己的地区菜价：
1. 在网页左侧点击“下载 CSV 模板”。
2. 保留表头，替换成当地 date、name、price、unit 数据。
3. 填写地区名称并上传 CSV。
4. 页面会按当地菜价重新评分和推荐。

默认不上传文件时，系统使用北京新发地离线示例数据。
网站打不开时，请确认启动窗口仍在运行，并手动访问 http://localhost:8501。
启动失败时窗口会停留并显示原因；同目录的 startup.log 会记录启动阶段。
