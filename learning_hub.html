Kaggle 完全使用指南

1

注册账号

  1. 打开 kaggle.com，点击右上角 Register
  2. 可以用 Google 账号一键登录，或用邮箱注册
  3. 注册后去邮箱确认，即可免费使用全部功能

不需要手机号、不需要付费。注册完就可以开始学课程了。

2

Kaggle Learn 课程界面

打开任意课程（如 Python 课），页面结构：

  • 左侧目录：课程章节，按顺序学
  • 中间正文：教程内容 + 代码示例
  • 底部按钮："Run" 运行代码、"Submit" 提交练习
  • 每章末尾：一个练习题，做对才能进入下一章

所有代码都在 Kaggle Notebook（在线 Jupyter 环境）里运行，不用装任何软件。

3

如何有效上 Kaggle 课程

  1. 先通读教程：理解概念，不要只看代码
  2. 自己动手打字：别复制粘贴，亲手敲代码效果更好
  3. 做练习：每节课的练习必做，这是巩固的关键
  4. 修改参数试试：改一下函数参数，看结果怎么变——好奇心是最好的老师
  5. 如果不理解：返回上一步重看，或者去 Google 搜这个知识点
4

Kaggle Notebooks 深入使用

学完课程后，真正的战场在 Notebooks：

  • 创建 Notebook：点 "Code" → "New Notebook" 开始写代码
  • Cell 类型：Code（写 Python/SQL）、Markdown（写说明文字）
  • 运行：点 Cell 左边的播放按钮，或按 Shift+Enter
  • 导入数据：右侧 "Add Data" → 搜索数据集添加
  • Fork 别人的：在别人的 Notebook 点 "Fork" 复制一份，然后改着玩
  • 保存：自动保存，也可以点 "Save Version" 保存版本
5

如何用数据集做项目

  1. 打开想用的数据集页面（如 电商数据集）
  2. 点右上角 "New Notebook"，自动创建一个带该数据集的 Notebook
  3. 在 Notebook 里写代码：导入数据 → 清洗 → 分析 → 可视化
  4. 完成后点 "Save Version"，选择 "Save & Run All" 确保结果可复现
  5. Notebook 链接可以直接分享到简历上作为作品展示
6

Kaggle 其他有用功能

  • Competitions：进阶后可以参加比赛，但新手先别看，容易打击信心
  • Discussions：有不懂的可以搜讨论区，很活跃
  • Datasets：海量免费数据集，按热度/类型筛选
  • Models：预训练模型，新手暂时不需要
  • 论坛：右上角 "Community" → "Forum" 可以提问

高效学习指南

1

70/20/10 原则

学习任何数据分析技能的最佳配比：

  • 70% 实践：打开 Kaggle 写代码、改参数、做项目
  • 20% 学习：看教程、读文档、学新概念
  • 10% 理论：补背景知识，如统计学原理

不要花太多时间看视频教程，动手写才是最快的。

2

学习顺序建议

前 2 周：SQL + Python/Pandas 并行

  • 上午：Kaggle SQL 课程（1-2 小时）
  • 下午：Kaggle Python + Pandas 课程（1-2 小时）
  • 晚上：SQLZoo 刷题巩固（30 分钟）

第 3 周：可视化 + 统计学

  • Kaggle 可视化课程 + 可汗学院统计学

第 4 周：完成第一个完整项目

  • 用之前的数据集做完整分析流程
  • 把 Notebook 整理好，保存为作品
3

避免这些坑

  • 不要完美主义：不用学完所有知识再动手，学一个概念立刻练习
  • 不要只收藏不看：收藏了 20 个教程不如动手写完 1 个
  • 不要抄代码不思考：复制别人的代码时，要理解每一行在做什么
  • 不要跳过 SQL：面试几乎必考，每天抽 30 分钟刷题
  • 不要放弃太快：遇到报错是正常的，报错信息就是最好的老师
4

每天 1 小时高效学习法

如果你时间有限，这是一个可执行的每日方案：

  • 0-25 分钟：Kaggle 课程学 1 个小节
  • 25-50 分钟：在 Notebook 里动手练习刚学的概念
  • 50-60 分钟：整理笔记，把今天学的知识点写下来

每天坚持比周末猛学 6 小时更有效。

5

如何做笔记（面试有用）

  • 记下 常用函数和语法：如 groupby 怎么用、窗口函数怎么写
  • 记下 自己犯过的错：报错原因 + 解决方案
  • 记下 面试常考题：SQL 窗口函数、留存率计算、AB 测试解读
  • 推荐工具：Notion、Typora 或简单的 Markdown 文件
6

学习目标设定 (SMART)

  • 第 1 周：完成 Kaggle Python + SQL 入门课程
  • 第 2 周：完成 Kaggle Pandas + SQL 进阶课程
  • 第 3 周：完成可视化课程 + 可汗学院统计学前 6 章
  • 第 4 周：完成一个完整数据分析项目，Notebook 发布到 Kaggle

做完这些，你就可以自信地投递实习简历了。
